# 機能要件

## 必須機能
- FastAPI プロジェクト作成（Python 3.13.3）
- Supabase SDK セットアップ・接続設定
- Clerk認証ミドルウェア実装（JWT検証）
- 基本ディレクトリ構造作成（Router-Service-Repository）
- CORS設定・環境変数管理
- 開発ツール設定（uvicorn、pytest、黒板）

# 制約・除外事項

## 技術制約
- Python 3.13.3必須（現在の環境バージョン）
- Supabase SDK使用（SQLAlchemy不使用）
- Clerk認証（管理者3名のみの招待制）
- Railway デプロイ想定

## ビジネス制約
- 実装期間: 1日以内
- 開発者1名での作業想定
- 管理者認証のみ（一般ユーザー登録なし）

## スコープ外
- 具体的なAPIエンドポイント実装（F-0301〜0306で実装）
- 本番デプロイ設定（F-0205で実装）
- 詳細な権限管理システム（Clerk管理画面のみ使用）
- パフォーマンス最適化設定（F-0703で実装）
