# F-0201: Next.js プロジェクト初期化

## 概要
Next.js 15 (App Router) + TypeScript + shadcn/ui を使用したフロントエンドプロジェクトの基盤構築

## ビジネス価値・対象ユーザー
- **価値**: 高品質で保守性の高い開発基盤により開発効率を向上、SEO対応でZIGZAGLAB認知拡大に貢献
- **対象**: フロントエンド開発者、デザイナー（コンポーネント確認用）、全開発チーム

## 優先度・依存関係
- **優先度**: 🔴 最高（全フロントエンド機能の前提条件）
- **前提条件**: なし
- **後続機能**: F-0401（トップページ）, F-0501（管理画面レイアウト）, F-0601（SEO基盤）
