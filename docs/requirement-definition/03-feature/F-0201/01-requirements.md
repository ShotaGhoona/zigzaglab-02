# 機能要件

## 必須機能
- Next.js 15 (App Router) プロジェクト作成
- TypeScript設定（strict mode）
- shadcn/ui インストール・基本コンポーネント導入
- 公開サイト・管理画面の分離ディレクトリ構成
- 環境変数設定（API・認証・Storage）
- ESLint + Prettier 設定

# 制約・除外事項

## 技術制約
- Node.js 18以上必須
- パッケージマネージャー: npm（統一）
- shadcn/ui テーマ: デフォルト使用（カスタマイズは後フェーズ）

## ビジネス制約
- 実装期間: 1日以内
- 開発者1名での作業想定

## スコープ外
- 本番デプロイ設定（F-0205で実装）
- Clerk認証の詳細設定（F-0101で実装）  
- 具体的なページ・コンポーネント実装（各機能で個別実装）
- パフォーマンス最適化設定（F-0703で実装）
