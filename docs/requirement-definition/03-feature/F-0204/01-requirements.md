# 機能要件

## 必須機能
- **Docker構成**: フロントエンド・バックエンド・データベースの統一コンテナ環境
- **環境変数管理**: .env設定・機密情報の安全な管理・環境別設定
- **開発ツール統一**: ESLint・Prettier設定
- **ローカル開発サーバー**: Next.js dev・FastAPI uvicorn・Supabase連携
- **ホットリロード**: フロント・バック両方でのファイル変更自動反映

## オプション機能
- 開発用テストデータ自動生成
- パフォーマンス監視ツール設定

# 制約・除外事項

## 技術制約
- **Docker**: 最新安定版使用（コンテナベース開発必須）
- **環境変数**: 機密情報は.env.local使用（Git管理外）
- **ポート設定**: フロントエンド3000・バックエンド8000・固定設定
- **Node.js**: 18.x以上（Next.js 15対応）
- **Python**: 3.13.3（FastAPI最新機能利用）

## ビジネス制約
- **実装期間**: 1日以内
- **対象環境**: macOS・Windows・Linux対応
- **チームメンバー**: 3名（橋本、山下、尾崎）の開発環境統一

## スコープ外
- 本番環境設定（F-0205で実施）
- CI/CDパイプライン（F-0205で実施）
- 自動テスト設定（各機能実装時に実施）
- データベースシーディング（F-0203で実施）
