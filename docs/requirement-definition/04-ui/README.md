# UI設計・ページ構成作成ガイド

機能要件定義から実装可能なUI設計とページ構成を作成するためのテンプレートです。

## ドキュメント構成

```markdown
# [プロジェクト名]ページ一覧・UI設計（[プロジェクト種別]）

## リビジョン履歴
| Version | Date | Author | Summary | Status | Reviewer |
|---------|------|--------|---------|--------|----------|

## 権限レベル凡例
| 権限 | 絵文字 | 説明 |
|------|--------|------|
| **公開** | 🌐 | 未認証ユーザーもアクセス可能 |
| **認証済み** | 🔐 | ログインユーザーのみ |
| **管理者** | 👑 | 管理者権限必須 |

## [セクション名]
| URL | ページ名 | 主要機能 | 権限 | 備考 |
|-----|----------|----------|------|------|
```

## セクション分類パターン

### Webサイト・コーポレートサイト
1. **メインページ** - トップ・会社概要・サービス紹介
2. **商品・サービス関連** - 一覧・詳細・カテゴリ別
3. **コンテンツ・情報** - ニュース・ブログ・資料
4. **営業支援・問い合わせ** - フォーム・資料請求・見積り
5. **法的・補助ページ** - 規約・プライバシー・サイトマップ
6. **管理画面** - CMS・分析・設定

### SaaS・Webアプリ
1. **認証・オンボーディング** - ログイン・登録・初期設定
2. **ダッシュボード・メイン機能** - 一覧・詳細・作成・編集
3. **ユーザー管理・設定** - プロフィール・アカウント・通知
4. **データ管理・分析** - インポート・エクスポート・レポート
5. **管理機能・運用** - システム設定・監視・ログ

### ECサイト
1. **商品発見・検索** - 一覧・検索・フィルタ・カテゴリ
2. **商品詳細・購入** - 詳細・レビュー・カート・決済
3. **ユーザーアカウント** - 登録・プロフィール・注文履歴
4. **管理機能** - 商品・ユーザー・注文・決済管理

## URL設計パターン

### 基本パターン
```
/[resource] - リソース一覧
/[resource]/[id] - リソース詳細
/[resource]/category/[category] - カテゴリ別
/admin/[resource] - 管理者向け
```

### 動的ルーティング
- `[id]` - 数値・UUID等のID
- `[slug]` - SEO向けスラッグ
- `[...param]` - 可変長パラメータ

## 主要機能・備考記述例

### 機能パターン
- **情報表示**: 一覧・詳細・検索・フィルタ・ページネーション
- **データ操作**: 作成・編集・削除・一括操作・インポート
- **コミュニケーション**: コメント・シェア・通知・レビュー
- **分析**: 統計・グラフ・レポート・ダッシュボード

### 技術的備考
- **レンダリング**: SSG・SSR・ISR・CSR
- **特殊機能**: 動的ルート・認証必須・API連携
- **SEO**: OGP設定・構造化データ・サイトマップ対象
- **UX**: レスポンシブ・アクセシビリティ・パフォーマンス最適化
